# Solo 单音分析（Beta）

`backend.solo.recognize_solo(path, duration, sensitivity, progress)` 接收一条音轨，返回现有音符格式：`start/end/midi/name/activation/bends/review`。时间以当前音频片段为零点；父任务负责原视频偏移。输出按时间排序，每个时刻最多一个音符，保留能检测出的休止和重复拨弦。未识别推弦、滑音、击勾弦或实际弦品；`bends` 为空，弦品仍由下游指法建议生成。

这个模式面向清楚的单线旋律，**不是从整首混音里自动分离主音吉他**。双音、延续的低音、其他乐器和残留人声可能使它跟随错误音高。应保留原有复音音符模式，让用户回听、修正；不能将 Solo 当作已验证的精度升级。

## 实现

- 使用已安装的 librosa 0.10.1 pYIN，无新增依赖或模型下载。参考 [librosa pYIN 官方文档](https://librosa.org/doc/0.10.2/generated/librosa.pyin.html) 的基频候选、voicing 与 Viterbi 序列估计接口。
- 22,050 Hz，1,024 样本帧，128 样本步长，C2–C7 范围，25 cents 音高网格；`n_thresholds=32`、`max_transition_rate=100`。按约四秒分块，两侧约 186 ms 上下文，截取各块中心后合并，防止整段 Viterbi 内存增长。
- 每个分块开始前调用 `progress`，取消异常直接传播。进度为 56、60–84、87；没有失败后偷偷退回另一引擎的行为。
- 独立短窗 RMS 门控保留静音，修补有声且两侧同音高的极短缺口；稳定音高至少 40 ms。能量明显上升时拆开重复音。输出不添加同一音符的高次谐波声部。
- `activation` 是 pYIN 的有声概率汇总，**不是音符正确率或力度**。较短、不稳定、弱有声的音符标记 `review`，其他音符也仍需要回听。

## 2026-09-16 验证

`tests/test_solo.py` 的八项真实音频信号测试通过（没有模拟 pYIN 输出）：D2–E6 的精确 MIDI 八度、第二泛音强于基频、连续同音重复拨弦和休止、75 ms 快速音符、跨分块的五秒长音、静音、非周期噪声、片段结束截断、分块之间取消。静音/噪声采用参数化测试。运行命令：

```sh
.venv-audio/bin/python -m pytest tests/test_solo.py -q
```

这些合成测试验证基础行为，不能替代真实演奏准确率。

另对仓库已有 GuitarSet 固定回归集中的六段 `solo` 麦克风录音运行新引擎，未按结果调参。使用同一 `scripts/benchmark_transcription.py` 评价器：音高 ≤50 cents、起音 ≤50 ms、一对一匹配，结束容差为 max(50 ms, 标注时长的 20%)，没有时间平移。

| 六段、490 个标注音符 | Solo pYIN | 已保存的 Basic Pitch 基线 |
| --- | ---: | ---: |
| 音高 + 起音精确率 | 63.86% | 73.91% |
| 音高 + 起音召回率 | 68.16% | 90.20% |
| 音高 + 起音 F1 | 65.94% | 81.25% |
| 加入结束时间的 F1 | 49.75% | 58.46% |

Solo 输出 523 个音符，334 个满足音高与起音条件，252 个再满足结束条件。六段每段起音 F1 分别为 52.48%、64.34%、55.50%、87.39%、63.29%、84.38%。标记为 `solo` 的录音仍有多个同时演奏/持续的音符，例如第一段开头有三个同时起音，所以并非纯单线验收集；该限制也不能掩盖新引擎当前真实成绩低于原基线的事实。

本轮没有逐音人工验收，没有达到 [已有发布目标](TRANSCRIPTION-QUALITY.md)，不能称作专业或可靠的自动扒谱。完整结果和逐段音符保存在本机忽略目录 `verification/solo/guitarset-report.json`。GuitarSet 来源与 CC-BY-4.0 归属沿用 `verification/transcription-quality/manifest.json`；不将录音打包进产品。

性能：六段 22–29 秒实录本轮耗时 8–43 秒，机器同时运行其他任务，不能作为稳定 SLA。180 秒持续 A3 的完整分块运行耗时 51.70 秒，只输出一个 A3（0.0145–179.9982 秒），未因分块重复起音；进入分块推理后相邻进度回调最大间隔 2.57 秒。记录在 `verification/solo/long-input-report.json`；因磁盘空间不足，长信号在内存输入，仅该长时测试不包含文件解码时间。
